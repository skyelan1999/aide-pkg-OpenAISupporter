# OpenAISupporter 0.1.0：来源与边界

核验时间：2026-10-30。实现参照 DeepSeekSupporter 的 providerSupport protocol 1；宿主负责安装校验、精确匹配、启停、价格快照与凭证。

## 已核验的官方来源

- [价格](https://developers.openai.com/api/docs/pricing)：采用 Standard，单位 USD／百万 token。
- [GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra)：10／1／50；输入超过 272K 后输入与缓存价 ×2、输出价 ×1.5，窗口 1.05M。
- [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol)：2／0.1／10；相同长上下文倍率与窗口。
- [GPT-6.1 Terra](https://developers.openai.com/api/docs/models/gpt-6.1-terra)：1／0.05／5；相同长上下文倍率与窗口。
- [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)：0.1／0.01／0.5；相同长上下文倍率与窗口。
- [模型列表接口](https://developers.openai.com/api/reference/resources/models/methods/list)：`GET /v1/models` 返回账户可用模型。插件不替代宿主模型同步。
- [组织 Costs](https://developers.openai.com/api/reference/resources/admin/subresources/organization/subresources/usage/methods/costs)：Admin Key 查询费用记录，与余额含义不同。

不把 ChatGPT/Codex 订阅等同 API 余额，不使用旧 Dashboard 私有账单接口，不向插件传递模型 Key/Admin Key，不声明宿主不支持的余额格式。

## 宿主兼容性

Aide `main` 已包含美元计价提交 `40b6e96bead57e19f2f4e5121b147df0a1aeb1db`，验收基线为 `5446e616f04ea776bccfcb7b8c506758c8164be4`。设置最低版本为 0.1.17.6 RC1；不修改主程序，也不改动用户正在运行的 Aide。

只声明 `https://api.openai.com/v1`；根路径、代理、Azure、区域域名、附加 URL 路径或未知模型不匹配。USD 原价与 CNY 分币种保存，不做汇率转换。未命中、停用或卸载后由宿主管理手动费率回退；插件命中时遵循宿主现有价格优先级。

长上下文分档按完整输入量判断，272000 包含在短档，272001 进入长档；使用有界上限避免对异常用量继续套价。宿主费率预览以输入量 0 查询，显示短档；实际记账按该次调用输入量选档。

缓存写入独立费用无法用现有 priceIn/priceInCacheHit/priceOut 三项完整表达，本版仅计缓存命中与普通输入／输出。其他服务等级、地区溢价和非 token 费用不自动计入。档案不是实际账单，也不会保证未来别名含义或价格不变。

## 验证方法

插件单元检查与确定性打包：`npm test`、`python3 scripts/package.py`。

宿主测试直接调用实际 ZIP 的生产安装解析器和上传接口，再验证启停、只读余额不支持、精确端点／模型、272K 阶梯、缓存用量与 USD/CNY 分离、未知模型手动回退。可将仓库 `test/host-acceptance.go.txt` 作为临时 Go 测试挂载到 Aide `internal/server/openai_release_test.go`，设置 `AIDE_OPENAI_RELEASE_ZIP` 指向打包 ZIP 后运行 `go test -race -mod=vendor ./internal/server -run '^TestOpenAIRelease'`。

真实账户、付费请求和浏览器操作不属于上述离线宿主测试结果；本次发布不声称完成这些验证。
